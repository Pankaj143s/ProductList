# 🛒 Product List – Modern Product Grid UI

A responsive and visually appealing product list layout showcasing products in a grid with hover animations and elegant typography. Ideal for eCommerce or catalog-style presentations.

> 🚀 **Live Preview**: [https://pankaj143s.github.io/ProductList/](https://pankaj143s.github.io/ProductList/)

---

## ✨ Features

- Clean and modern product grid
- Smooth hover effects on product images
- Responsive layout across all devices
- Suitable for portfolios, stores, or catalogs
- Deployed via GitHub Pages

---

## 🛠 Tech Stack

- **HTML5**: Structured markup
- **CSS3**: Styling and layout with hover effects
- **JavaScript** *(if used)*: For interaction (optional)
- **Deployment**: [GitHub Pages](https://pages.github.com/)
